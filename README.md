# FINE3300-2026-A1
FINE 3300 Assignment 1 - Python for Finance

## Overview
This project is a USD/CAD currency converter. It reads the Bank of Canada exchange rate file, takes the latest USD/CAD rate (the last row of the file), and converts an amount from one currency to the other.

The repository contains two versions of the program:
- **Part 1** (`ExchangeRates.py`): one I wrote myself, without AI
- **Part 2** (`ExchangeRatesAI.py`, Vibe Coding): one generated by a large language model

## Sample Output
Latest rate used by both programs (2025-01-01): 1 USD = 1.3978 CAD

| Conversion | Result |
|---|---|
| $100,000.00 USD → CAD | $139,780.00 CAD |
| $100,000.00 CAD → USD | $71,540.99 USD |

## Comparison
Both programs produce the same conversion results ($100,000.00 USD = $139,780.00 CAD and $100,000.00 CAD = $71,540.99 USD), but they differ in structure, length, and error handling. My code is shorter and more straightforward, while the ExchangeRates class reads through each row of the CSV file, updating the exchange rate until it reaches the final row, which contains the most recent rate. The convert() method then multiplies the amount by the rate to convert USD to CAD or divides it to convert CAD to USD. The AI-generated code (Claude Opus 5.5) is about twice as long (82 lines vs. 41) and more structured. It loads all rows into a list and takes the last one directly, and it separates tasks into a helper method for reading the file and a main() function for user input. Both versions are commented, but differently, mine explains each step with inline comments, while the AI’s uses docstrings to describe what each class and method does. The biggest difference is error handling, where if a user enters a word instead of a number, the AI’s program asks them to try again instead of crashing. It also accepts lowercase inputs like “usd,” where my code would return the original amount without converting it. The AI’s first version did not run because it referenced the wrong file name, and it took two more prompts to fix. This showed me that AI-generated code still needs to be carefully tested. Overall, my code is simpler, while the AI’s version is more robust but longer.
