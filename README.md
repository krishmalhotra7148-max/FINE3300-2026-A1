# FINE3300-2026-A1
FINE 3300 Assignment 1 - Python for Finance

## Overview
This project is a USD/CAD currency converter. It reads the Bank of Canada exchange rate file, takes the latest USD/CAD rate (the last row of the file), and converts an amount from one currency to the other.

The repository contains two versions of the program:
- **Part 1** (`ExchangeRates.py`): one I wrote myself, without AI
- **Part 2** (`ExchangeRatesAI.py`, Vibe Coding): one generated by a large language model

## Sample Output
Latest rate used by both programs (2025-01-01): 1 USD = 1.3978 CAD

| Conversion | Result |
|---|---|
| $100,000.00 USD → CAD | $139,780.00 CAD |
| $100,000.00 CAD → USD | $71,540.99 USD |

## Comparison
Both programs produce the same conversion results ($100,000.00 USD = $139,780.00 CAD and $100,000.00 CAD = $71,540.99 USD), but they differ in their structure, length, and error handling. My code is shorter and more straightforward. For instance, the `ExchangeRates` class reads through each row of the CSV file, updating the exchange rate until it reaches the final row, which contains the most recent rate. The `convert()` method then multiplies the amount by the rate to convert USD to CAD or divides it to convert CAD to USD. In comparison, the AI-generated code (Claude Opus 5.5) is approximately three times longer and uses a more structured approach. It separates tasks into different functions, such as reading the CSV file and handling user input through a `main()` function, while also including comments to explain the code. One major advantage of the AI-generated version is its error handling. For example, if a user enters a word instead of a number, the program prompts them to try again rather than crashing. It also accepts lowercase currency inputs, such as "usd," where my code would return the original amount without converting it. However, the AI's initial code did not run correctly because it referenced the wrong file name, and it took two more prompts to resolve the issue. This showed me that even AI-generated code needs to be carefully tested and corrected. Overall, my code is simpler, while the AI-generated version is more user-friendly and better equipped to handle unexpected inputs.
