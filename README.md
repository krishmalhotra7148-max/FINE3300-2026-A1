# FINE3300-2026-A1
FINE 3300 Assignment 1 - Python for Finance

## Overview
This project is a USD/CAD currency converter. It reads the Bank of Canada exchange rate file, takes the latest USD/CAD rate (the last row of the file), and converts an amount from one currency to the other.

The repository contains two versions of the program:
- **Part 1** (`ExchangeRates.py`): one I wrote myself, without AI
- **Part 2** (`ExchangeRatesAI.py`, Vibe Coding): one generated by a large language model

## Sample Output
Latest rate used by both programs (2025-01-01): 1 USD = 1.3978 CAD

| Conversion | Result |
|---|---|
| $100,000.00 USD → CAD | $139,780.00 CAD |
| $100,000.00 CAD → USD | $71,540.99 USD |

## Comparison
Both programs produce the exact same conversion results ($100,000.00 USD = $139,780.00 CAD and $100,000.00 CAD = $71,540.99 USD), but they differ in design, complexity, and usability. My code is shorter (41 lines versus 82) and more direct, looping through the CSV file line-by-line to find the latest rate, while the AI version loads the data into a list, grabs the final entry directly, and separates the logic into distinct helper functions and a main execution block. For documentation, I relied on inline comments to explain each step, where the AI used docstrings to describe its classes and functions. The biggest difference is error handling, the AI version accepts lowercase currency inputs and prompts the user to try again if they enter letters instead of numbers, preventing crashes that would break my simpler script. However, the AI code did reference the wrong file name initially and required two follow-up prompts to run properly. Ultimately, my code is simpler and more concise, while the AI's version is more resilient to bad input despite requiring troubleshooting to get right.
